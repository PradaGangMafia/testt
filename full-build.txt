P02 — docs/SPEC.md
--------------------------------------------------------------------------------

Write the frozen byte-format specification. No networking.

Frame: magic 4 bytes 43 32 00 01; version u16 LE; msg_type u8 (1 heartbeat,
2 task, 3 result, 4 rotate, 5 upgrade); route_tag 8 bytes, all-zero means all
agents; epoch u64 LE monotonic per route_tag, set by the coordinator, never
resets; nonce 24 random bytes; payload_len u16 LE before padding; payload CBOR
zero-padded; signature 64 bytes Ed25519 over every preceding byte.

Size classes 256/512/1024/4096, smallest that fits. Maximum payload 3967.
Padding is outside the AEAD ciphertext and inside the signed region; non-zero
padding is BadPadding.

Mandatory receiver order, stated as mandatory: magic and version, signature,
epoch freshness, decrypt, CBOR, dispatch.

AEAD XChaCha20-Poly1305, AAD is the header from magic through payload_len.
Signing and encryption keys are separate. CBOR canonical, definite-length,
sorted keys; unknown map keys tolerated.

Task bodies: Ping {}; Shell { argv: [string], timeout_s: u16, shell: bool };
Fetch { url, dest }. Result { task_epoch, ok, stdout, stderr, code }.
Duplicate suppression is a 64-epoch window per route_tag, persisted.

CONSTRAINTS: prose and byte tables only; no code; every field typed and sized.
ACCEPTANCE: an engineer who never spoke to us produces byte-identical output
for every case from this document alone; an ambiguity list closes the file.

P03 — msgfmt encode
--------------------------------------------------------------------------------

Implement encode only. Dependencies: ed25519-dalek 2, chacha20poly1305 0.10,
serde_cbor 0.11, rand 0.8, thiserror 1.

API: MsgType; Task { route_tag, epoch, body }; TaskBody; encode_task(&Task,
&enc_key, &SigningKey). Padding to the smallest class, payload_len before
padding, signature over everything preceding it, nonce from OsRng, AAD the
header.

CONSTRAINTS: pure, no I/O, no async; decode comes next; no other files.
ACCEPTANCE: build and clippy clean; one unit test encodes each TaskBody and
asserts the frame is exactly 256 bytes.

--------------------------------------------------------------------------------
P04 — msgfmt decode, verify, decrypt
--------------------------------------------------------------------------------

Add verify(bytes, &VerifyingKey), decode(bytes, &enc_key), decode_checked(bytes,
&VerifyingKey, &enc_key, &mut u64). decode_checked performs the mandatory order
and updates the epoch only after every step succeeds.

Distinct variants: BadMagic, BadVersion, BadSignature, StaleEpoch, BadAead,
BadCbor, UnknownMsgType, Truncated, BadLength.

CONSTRAINTS: verification before decryption, stated in a doc comment;
StaleEpoch is hard; no mutation on failure paths.
ACCEPTANCE: round-trip identity; any single flipped bit is BadSignature; the
same bytes twice is StaleEpoch; wrong key is BadAead not a panic; truncation at
every length errors without panic.

--------------------------------------------------------------------------------
P05 — vectors
--------------------------------------------------------------------------------

40 committed vectors in tests/vectors/, plus a harness. Cover each body, every
class boundary (255/256/257, 511/512/513, 3966/3967), zero and all-one tags, a

at byte 0/16/32/len-1, wrong enc key, wrong sign key, epoch 0 and u64::MAX.

CONSTRAINTS: generated once and committed, not per run; one test fn per vector;
no fuzzing crate.
ACCEPTANCE: all 40 pass; every err vector returns its exact named variant; test
names identify the case alone.

P60 — re-enrolment
--------------------------------------------------------------------------------

adminctl agents grant --tag [--expires] emits a signed EnrolmentGrant token.
With no key and a token the agent generates a key and publishes a signed
EnrolRequest; db ingest validates signature, expiry and single-use nonce then
enrols at the token's tag.

ACCEPTANCE: total wipe plus token re-enrols in two cycles and tasks resume;
reused token refused; expired refused; no token and no key idles cleanly.

--------------------------------------------------------------------------------
P61 — tamper detection
--------------------------------------------------------------------------------

At start and every 50 cycles: key 0600, state 0700, binary not world-writable,
self hash matches, chattr +i status on Linux, codesign on macOS, exe ACL on
Windows. Each failure is a tamper finding with a stable dedupe_key.

ACCEPTANCE: 0644 key raises key_mode; modified binary raises a hash finding;
healthy raises none; non-root reports unsupported.

--------------------------------------------------------------------------------
P62 — boot resilience
--------------------------------------------------------------------------------

Empty primary with a verifying mirror restores before the first poll and logs
once. Clock below the highest stored epoch warns without rejecting. Grace drops
to 0..10s after a restore. doctor fails on tmpfs-only state.

ACCEPTANCE: cold start from a mirror restores under 10s grace; clock back a year
warns and still accepts; tmpfs-only fails doctor.

--------------------------------------------------------------------------------
P63 — resilience acceptance
--------------------------------------------------------------------------------

r01 kill loop, r02 binary deleted, r03 all copies bad, r04 state wiped, r05
mirror corrupt, r06 re-enrol, r07 token reuse, r08 service removed, r09 unit
stopped, r10 perm tamper, r11 binary modified, r12 tmpfs, r13 clock back.

ACCEPTANCE: all pass.

P64 — doctor
--------------------------------------------------------------------------------

agentd doctor [--json]: binary path and writability, key perms, state
writability, lock acquirable, config validity, every relay /health, peer table,
mod abi, listen bindability, DB writability, disk headroom. Exit 0/1/2.

ACCEPTANCE: deleted binary fails; 0644 key warns; an unreachable relay fails
without blocking other checks.
